## Interview Simulation and Story Prep

Questions to have an answer ready for.

- "Walk me through a multi-agent system you built"
  - graph topology, state design, failure modes, how retries and fallbacks were handled
- "How do you evaluate an LLM system before shipping?"
  - golden sets, offline benchmarks, human review, production monitoring, mapped to RAGAS metrics
- "How did you handle latency vs quality trade-offs in a RAG system?"
  - chunking strategy, reranker cost, async retrieval, caching
- "How do you integrate an AI system into an enterprise Azure environment?"
  - Managed Identity, Key Vault, private endpoints, App Insights
- "When would you NOT use an LLM?"
  - deterministic rules, latency constraints, cost, auditability requirements
