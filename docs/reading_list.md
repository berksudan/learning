# Reading List

## Data Engineering

- https://www.ssp.sh/brain/data-engineering-concepts/ - data engineering concepts wiki covering storage, modeling, orchestration, and analytics engineering.

## System Design

- https://github.com/donnemartin/system-design-primer - system design study guide with worked design questions and Anki decks.

## Agentic AI and LLM Orchestration

- https://academy.langchain.com/courses/intro-to-langgraph - LangChain Academy intro to LangGraph. Modules 1-4 cover state, nodes, edges, and branching. Modules 5-7 cover persistence, human-in-the-loop, and memory.
- https://langchain-ai.github.io/langgraph/concepts/multi_agent/ - LangGraph multi-agent conceptual guide, supervisor, swarm, and handoff patterns.
- https://langchain-ai.github.io/langgraph/how-tos/streaming/ - LangGraph how-to on streaming in agents.
- https://www.anthropic.com/research/building-effective-agents - Anthropic, Building Effective Agents. Orchestrator, subagent, and tool-use patterns.
- https://www.deeplearning.ai/short-courses/ai-agents-in-langgraph/ - DeepLearning.AI short course on AI agents in LangGraph.
- https://www.deeplearning.ai/short-courses/functions-tools-agents-langchain/ - DeepLearning.AI short course on functions, tools, and agents with LangChain.
- https://python.useinstructor.com/concepts/models/ - Instructor library concepts and quickstart for Pydantic-based structured LLM outputs.
- https://platform.openai.com/docs/guides/structured-outputs - OpenAI structured outputs guide, schema validation, tool use, and JSON mode.
- https://microsoft.github.io/multi-agent-reference-architecture/index.html - Microsoft multi-agent reference architecture.

## RAG, Evaluation, and the Azure Stack

- https://www.deeplearning.ai/short-courses/building-evaluating-advanced-rag/ - DeepLearning.AI course on building and evaluating advanced RAG, sentence-window, auto-merging, and reranking.
- https://docs.ragas.io/en/latest/concepts/metrics/ - RAGAS metrics docs, faithfulness, answer relevancy, and context recall.
- https://www.deeplearning.ai/short-courses/evaluating-debugging-generative-ai/ - DeepLearning.AI course on evaluating and debugging generative AI, golden sets, human review, and monitoring.
- https://mlflow.org/docs/latest/llms/llm-evaluate/ - MLflow LLM Evaluate, logging and comparing LLM eval runs.
- https://mlflow.org/docs/latest/llms/deployments/ - MLflow AI Gateway and prompt engineering UI overview.
- https://learn.microsoft.com/en-us/azure/search/hybrid-search-overview - Azure AI Search hybrid search overview, BM25 with vector search and a semantic reranker.
- https://learn.microsoft.com/en-us/azure/search/vector-search-overview - Azure AI Search vector search concepts and index design.
- https://learn.microsoft.com/en-us/azure/ai-foundry/what-is-azure-ai-foundry - Azure AI Foundry overview, model catalog, deployments, and prompt flow.
- https://learn.microsoft.com/en-us/azure/ai-services/agents/overview - Azure AI Foundry Agent Service, the Azure-native agent runtime.
- https://learn.microsoft.com/en-us/azure/ai-foundry/concepts/evaluation-approach-gen-ai - Azure AI Foundry built-in evaluation for safety, groundedness, and relevance.

## Production Patterns

- https://eugeneyan.com/writing/llm-patterns/ - Eugene Yan, patterns for LLM systems, evals, RAG, agents, and caching.
- https://fastapi.tiangolo.com/async/ - FastAPI async IO guide, async endpoints, background tasks, and lifespan.
- https://docs.python.org/3/library/asyncio-task.html - Python asyncio tasks, gather, TaskGroup, and timeouts.
- https://www.guardrailsai.com/docs/concepts/guard - Guardrails AI validators, rail specs, and output correction.
- https://learn.microsoft.com/en-us/azure/azure-monitor/app/app-insights-overview - Azure Monitor and Application Insights for AI workloads.
- https://learn.microsoft.com/en-us/azure/key-vault/general/developers-guide - Azure Key Vault and Managed Identity, the access pattern for enterprise AI systems.

## Books

- AI Engineering, Building Applications with Foundation Models (O'Reilly) - product and system design on top of foundation models, with evaluation strategies for shipping safer apps.
- Hands-On Large Language Models, Language Understanding and Generation (O'Reilly) - code-first projects covering summarization, semantic search, and classification.
